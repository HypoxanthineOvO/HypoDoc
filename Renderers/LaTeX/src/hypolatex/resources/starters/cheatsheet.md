# 常用操作

此模板使用普通标题、列表和表格，便于预览与 PDF 共享正文。PDF 会采用紧凑排版，预览端保持普通文档布局。

| 操作 | 用途 |
| --- | --- |
| `hypolatex doctor` | 检查 PDF 构建依赖 |
| `hypolatex convert` | 输出可审阅的 TeX |
| `hypolatex build` | 生成 PDF |

# 常用公式

- 平方差：$a^2-b^2=(a-b)(a+b)$。
- 导数：$\frac{d}{dx}x^n=nx^{n-1}$。

# 练习

默认学生版隐藏答案和解析。需要答案时，在构建命令中加上 `--answer-mode review`。

:::: {.qa #derivative kind="open" title="基础练习"}
::: {.question title="题目"}
求函数 $f(x)=x^3$ 的导数。
:::

::: {.hint title="提示"}
使用幂函数的求导规则。
:::

::: {.answer title="参考答案"}
答案：$f'(x)=3x^2$。
:::

::: {.solution title="解析"}
幂函数满足 $\frac{d}{dx}x^n=nx^{n-1}$，令 $n=3$ 即可。
:::
::::

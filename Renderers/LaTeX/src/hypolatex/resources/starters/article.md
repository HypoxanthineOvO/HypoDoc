# 问题与结论

先让读者知道本文回答什么，以及当前结论是什么。正文保持连续的阅读节奏，不把每一段都装进 Box。

## 方法与依据

给出必要的定义、假设和推导。中英文正文与公式使用协调的字体，例如相对误差

$$e_{\mathrm{rel}}=\frac{|x-\hat{x}|}{|x|},\qquad x\ne 0.$$

说明符号的含义，再解释结果。不要只列公式，也不要用大段背景遮住真正的结论。

| 内容 | 应回答的问题 |
| --- | --- |
| 方法 | 做了什么，为什么这样做？ |
| 证据 | 结论由什么支撑？ |
| 边界 | 哪些情形尚未覆盖？ |

# 限制与下一步

把已验证的事实与尚待检验的判断分开。简短文档通常不需要目录；需要时可设置 `toc: true`，目录仍与正文连续排版。

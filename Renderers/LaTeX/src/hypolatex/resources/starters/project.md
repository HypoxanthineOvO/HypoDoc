# 项目目标

::: {.objective title="目标"}
说明要解决的问题、目标读者和期望结果。
:::

::: {.task title="任务"}
把工作分解成可以独立检查的步骤。
:::

::: {.requirement title="要求"}
记录必须满足的约束，不把可选想法写成硬性要求。
:::

::: {.deliverable title="交付物"}
交付 Markdown 源文件、实际使用的素材和最终 PDF。
:::

## 方案比较

::: {.table #options kind="comparison" caption="方案比较"}
| 方案 | 适用场景 | 取舍 |
| --- | --- | --- |
| 简短说明 | 快速沟通 | 信息精简 |
| 完整报告 | 深入评审 | 需要更多材料 |
:::

::: {.checklist title="交付检查"}
- [ ] 目标明确。
- [ ] 材料来源可追溯。
- [ ] PDF 内容与源文件一致。
:::

::: {.rubric title="验收标准"}
用可以观察的结果判断任务是否完成。
:::

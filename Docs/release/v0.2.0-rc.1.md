# HypoDoc v0.2.0-rc.1

Status: local release candidate; not tagged, published, or uploaded.

## Highlights

- Adds a renderer-owned SlideDeck projection with located diagnostics and immutable node sharing.
- Adds fixed 16:9 waterfall and presentation rendering across Web, Desktop, and VS Code preview.
- Adds Desktop workspace, import/export, settings, presentation navigation, and fullscreen workflows.
- Hardens Hypo-LaTeX profile/theme configuration, pinned Pandoc enforcement, resource containment,
  placeholder policy, and deterministic PDF builds.
- Restructures the public HypoDoc authoring Skill around canonical profiles, capability-aware themes,
  strict export evidence, and reproducible evals.
- Records performance gates and cross-renderer visual/semantic evidence from C002.

## Version Mapping

- JavaScript workspace packages, Desktop, and VS Code extension: `0.2.0-rc.1`.
- Python Hypo-LaTeX distribution (PEP 440): `0.2.0rc1`.
- Product-facing release label: `v0.2.0-rc.1`.

## Validation

- Workspace typecheck and 34 JavaScript/TypeScript tests passed.
- Hypo-LaTeX: `269 passed, 12 skipped` with pinned Pandoc 3.10.
- Desktop production build, VS Code production build, Electron smoke, cold-start Playwright workflows,
  performance gates, and visual evidence checks passed during C002 closeout.

## Before Stable v0.2.0

- Run remote CI from the final candidate commit.
- Rebuild and smoke-test Linux, Windows, and macOS installers from that commit.
- Build the VSIX and Python distribution from the same source revision.
- Create release artifact hashes, then tag and publish only after explicit approval.

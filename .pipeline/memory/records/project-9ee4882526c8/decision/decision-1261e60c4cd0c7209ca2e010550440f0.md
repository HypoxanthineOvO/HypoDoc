# 业务整合与来源权威策略

HypoDoc 迁移是一次业务整合。三个来源仓均须批判性核验，不能被视为不可修改的唯一真理。允许基于已确认业务目标、产品边界、显式 Spec/兼容合同与跨 renderer 验证证据修改内容、结构、命名和接口；来源历史用于 provenance 与回退，业务改造通过独立提交记录理由和影响。
